所沢市のごみ収集カレンダー

所沢市の公開済み地区別収集日程を、いつものカレンダーで確認できます。

無料・登録不要。住所の入力は不要です。

Issueでリクエスト PRで追加する

所沢市内の地区の追加にご協力ください。他の自治体は対象外です。公式日程と利用条件の確認方法は貢献ガイドをご覧ください。住所などの個人情報は記載しないでください。

所沢市の地区から探す

地区名を押すと照会URLをコピーできます。カレンダーアプリの「URLで追加」や「照会カレンダー」に貼り付けてください。

カレンダーへの追加方法

読み取り専用の照会カレンダー

Mac・iPhoneで使う

地区名を押して照会URLをコピーし、Macでは「ファイル → 新規照会カレンダー」に貼り付けて追加します。

iPhoneでは「カレンダー → カレンダーを追加 → 照会カレンダーを追加」から設定できます。「リンク・収録期間・出典」内の「Apple Calendarで照会」から開くこともできます。

Appleの詳しい手順

Google Calendarで使う

パソコンのGoogle Calendarで「他のカレンダー」の「＋」から「URLで追加」を選び、コピーしたHTTPS URLを貼り付けます。

追加したカレンダーは、同じアカウントのスマートフォンでも表示できます。更新の反映には時間がかかる場合があります。

Googleの詳しい手順

ファイルの読み込みではなく、URLで照会すると、公開後の訂正や新年度の日程を同じURLで受け取れます。

ご利用にあたって

Gomiwakeは所沢市の公式サービスではありません。公式情報を確認して日程を掲載しますが、変更や転記誤りの可能性があります。重要な収集情報は所沢市の案内や集積所の掲示でもご確認ください。収録期間外の予定は推測して掲載しません。

住所・位置情報の取得、アカウント登録、アクセス解析は行いません。日程の誤りはGitHubから報告できます。番地などの個人情報は記載しないでください。
